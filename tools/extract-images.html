🛠️ NISRAA – Base64 Image Extractor

Tool khas untuk extract gambar dari belinisraa.html dan kecikkan saiz fail

⚠️ Cara guna:
1. Buka belinisraa.html dalam text editor (Notepad++, VS Code, dll)
2. Select ALL (Ctrl+A) → Copy (Ctrl+C)
3. Paste dalam kotak di bawah → Klik "Extract Images"
4. Download semua gambar → Upload ke folder images/ dalam projek ini
